## Доменная область
Музей с выставочной деятельностью. Посетители музея могут просматривать актуальные выставки, проходящие в определённых залах, приобретать билеты на них и оставлять отзывы о посещении.

## Сущности

### User  
Пользователь системы, который может оформлять заказы и оставлять отзывы.  
- `id` — уникальный идентификатор  
- `name` — имя пользователя  
- `email` — электронная почта  
- `password` — пароль  
- `createdAt` — дата регистрации  

### Hall  
Зал, в котором проводятся выставки.  
- `id` — уникальный идентификатор  
- `name` — название зала  
- `capacity` — вместимость  

### Exhibition  
Выставка, проходящая в определённом зале в заданный период.  
- `id` — уникальный идентификатор  
- `name` — название  
- `description` — описание  
- `dateStart` — дата начала  
- `dateEnd` — дата окончания  
- `hallId` — зал (связь с Hall)  

### Order  
Заказ пользователя (покупка билетов).  
- `id` — уникальный идентификатор  
- `userId` — пользователь (связь с User)  
- `status` — статус заказа  
- `totalPrice` — общая стоимость  
- `createdAt` — дата создания  

### OrderItem  
Позиция в заказе (конкретные билеты на выставку).  
- `id` — уникальный идентификатор  
- `orderId` — заказ (связь с Order)  
- `exhibitionId` — выставка (связь с Exhibition)  
- `hallId` — зал (денормализованная связь)  
- `quantity` — количество билетов  
- `unitPrice` — цена за единицу  

### Feedback  
Отзыв пользователя.  
- `id` — уникальный идентификатор  
- `text` — текст отзыва  
- `createdAt` — дата создания  
- `userId` — пользователь (связь с User)  


## Связи между сущностями

- **User → Order**: один пользователь может иметь много заказов  
- **Order → OrderItem**: один заказ содержит много позиций  
- **Exhibition → OrderItem**: одна выставка может входить во множество заказов  
- **Hall → Exhibition**: один зал содержит много выставок  
- **User → Feedback**: один пользователь оставляет много отзывов
