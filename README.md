## Доменная область
Музей с выставочной деятельностью. Посетители музея могут просматривать актуальные выставки, проходящие в определённых залах, приобретать билеты на них и оставлять отзывы о посещении.

## Сущности

### User 
Посетитель музея, который может покупать билеты и оставлять отзывы.
- `id` — уникальный идентификатор
- `name` — имя пользователя
- `email` — электронная почта
- `password` — пароль
- `createdAt` — дата регистрации

### Hall 
Физический зал музея, в котором проводятся выставки.
- `id` — уникальный идентификатор
- `name` — название зала
- `capacity` — вместимость зала

### Exhibition
Выставка, проходящая в конкретном зале музея в определённый период.
- `id` — уникальный идентификатор
- `name` — название выставки
- `description` — описание
- `dateStart` — дата начала
- `dateEnd` — дата окончания
- `hallId` — зал (связь с Hall)

### Ticket
Билет, приобретённый пользователем на конкретную выставку.
- `id` — уникальный идентификатор
- `type` — тип билета (стандартный, льготный, экскурсионный)
- `price` — цена
- `purchasedAt` — дата покупки
- `userId` — пользователь (связь с User)
- `exhibitionId` — выставка (связь с Exhibition)

### Feedback 
Отзыв посетителя о музее.
- `id` — уникальный идентификатор
- `text` — текст отзыва
- `createdAt` — дата создания
- `userId` — пользователь (связь с User)

## Связи между сущностями

- **Hall → Exhibition**: один зал содержит много выставок
- **User → Ticket**: один пользователь покупает много билетов
- **Exhibition → Ticket**: на одну выставку продаётся много билетов
- **User → Feedback**: один пользователь оставляет много отзывов
